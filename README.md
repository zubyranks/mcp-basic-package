# Installation Guide
```json
{
  "mcpServers": {
    "add_tool": {
      "command": "/opt/homebrew/bin/uvx",
      "args": [
        "--from",
        "git+https://github.com/zubyranks/mcp-basic-package.git",
        "mcpserver"
      ]
    }
  }
}
```




## Run the mcp server from github
```
uvx --from git+https://github.com/zubyranks/mcp-basic-package.git mcpserver
```
